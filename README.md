# Sales Order & Inventory Management System

A Django-based web application for managing customers, products, sales orders, and inventory.

## Tech Stack

- **Backend:** Python, Django
- **Database:** MySQL
- **APIs:** Django REST Framework
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git and GitHub

## Project Structure

```text
sales-order-inventory-management/
│
├── accounts/       # User authentication and roles
├── config/         # Django project configuration
├── inventory/      # Stock management
├── masters/        # Customer and product management
├── reports/        # Sales and inventory reports
├── sales/          # Sales order management
├── manage.py
├── .env.example
├── .gitignore
└── README.md
```

## Planned Features

- Role-based authentication (Admin and Sales User)
- Customer and product management
- Sales order creation and management
- Inventory and stock movement tracking
- REST API endpoints
- Sales and inventory reports
- CSV product import
- Automated testing
